# Figure sources

Every figure on this site is generated by a script in this directory. Nothing here
is drawn by hand, traced from an image, or produced by an image generator.

## Regenerating

```bash
cd assets/figures_src
python tennis_model_f1.py          # -> ../img/figures/tennis_model_f1.svg
python ro_converged_fitness.py     # -> ../img/figures/ro_converged_fitness.svg
python ro_nn_generalization_gap.py # -> ../img/figures/ro_nn_generalization_gap.svg
```

Requires `matplotlib` and `numpy` only. Output is SVG with the embedded timestamp
suppressed, so a re-run reproduces the committed file byte for byte. If a script
stops reproducing its committed SVG, the figure and its caption are both suspect.

## The rule

Each script carries a `PROVENANCE` docstring naming the exact document, section,
and table its numbers come from. A number that cannot be traced to such a source
does not get plotted, and a project with no source gets no results figure rather
than an illustrative one.

| Figure                     | Source                                                                       |
| -------------------------- | ---------------------------------------------------------------------------- |
| `tennis_model_f1`          | `assets/pdf/TennisMatchPrediction_Project.pdf`, §5.4 Train/Test F1 table     |
| `ro_converged_fitness`     | `assets/pdf/CS7641_ML_Randomized_Optimization_Su24.pdf`, §IV.A–C             |
| `ro_nn_generalization_gap` | `assets/pdf/CS7641_ML_Randomized_Optimization_Su24.pdf`, Table IV `mean` row |

`ro_converged_fitness` is the one figure whose source states some values as
approximations in prose rather than in a table. That is disclosed in the script
docstring and in the caption on the site.

## Colour

Categorical colours are the first N entries of `PALETTE` in `_style.py`
(Okabe-Ito), assigned in fixed order and never cycled. Checked with the dataviz
skill's `validate_palette.js` against the light surface:

```
2 series  #0072B2,#D55E00                  all checks PASS
3 series  #0072B2,#D55E00,#009E73          all checks PASS
4 series  #0072B2,#E69F00,#009E73,#D55E00  PASS, contrast WARN on #E69F00
                                           -> direct labels required
```

Figures are light-mode only, matching `enable_darkmode: false` in `_config.yml`.
